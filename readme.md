# Análise de Conversão de Anúncios no Facebook

Este projeto aborda a análise exploratória e engenharia de atributos de dados de campanhas publicitárias no Facebook.

## Descrição do Repositório
* **Objetivo:** Processar métricas de anúncios e avaliar o desempenho de campanhas publicitárias.
* **Tecnologias:** Utilização de Python, Pandas, Matplotlib, Seaborn e Scikit-learn.

## Funcionalidades Principais
* Importação e tratamento de dados de campanhas a partir de fontes remotas.
* Engenharia de atributos com cálculo de CTR, CPC, CPA e indicadores de conversão[cite: 1].
* Visualização estatística através de gráficos de caixa (boxplots) e matrizes de correlação[cite: 1].
